Capture a Google ID token

This local POC creates a short-lived Ed25519 session key and binds it to a Google login nonce for Algorand TestNet. After you sign in, the token is verified against Google's public key and saved only in this project's ignored .env file.

Use the Google account you want to test. The token and your account identifier are not displayed here. The session private key stays in this browser tab and is discarded when you close or reload it.
